# SetSail

> SetSail is a revenue-operations and sales-AI platform (joining ZoomInfo) that automatically captures
> sales activity from email, calendar and contacts, syncs it to Salesforce, and layers AI revenue

> coaching — delivered to reps and leaders through Slack, email, the browser and Salesforce.

## Crawling posture

- https://www.setsail.co/robots.txt disallows every named AI and search crawler outright —
  ClaudeBot, Claude-User, GPTBot, ChatGPT-User, OAI-SearchBot, PerplexityBot, Googlebot, Bingbot,
  meta-externalagent, CCBot, Bytespider, MistralBot, cohere-ai, Amazon Q, Diffbot and others are all
  `Disallow: /`. The wildcard `User-Agent: *` rule allows everything except /setsail-events/, /team/
  and /author/. Agents identifying themselves under any of the named tokens should not fetch these
  URLs.

## APIs

- No public API. SetSail markets no developer program, publishes no API reference, and serves no
  OpenAPI, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema at any anonymously reachable
  path. The only SetSail-served HTTP API is the private backend of its customer application at
  https://app.setsail.co/api/, which returns `{"error":"Authentication Error"}` (HTTP 401) on every
  path and is undocumented.
- Across 104 public FAQ and knowledge-base pages, the only APIs discussed are the ones SetSail
  *consumes*: "SetSail requires API access to your CRM system (to write contacts and events) and
  read-only access to email and calendar for your reps."
